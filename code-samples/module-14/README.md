# Module 14: Introduction to AI in ColdFusion - Code Samples

This directory contains code samples aligned with **Module 14** (Introduction to AI), including ColdFusion 2025 AI foundations such as:

- AI architecture and providers (as covered in lessons)
- Installing AI packages (CFPM) where examples apply
- Entry points that may reference `ChatModel` / Agent in later lessons

Broader AI topics (MCP, vector stores, RAG, agents) have dedicated samples under **`module-15/` … `module-24/`** as well.

## Prerequisites

- ColdFusion 2025 with the AI feature update installed where required
- API keys for AI providers if using cloud services (see `Application.cfc` in `code-samples`)

## Directory Structure

```
module-14/
├── lesson-0/ …
```

## Usage

Each code sample may be provided in tag and script syntax:

- Files ending with `-tag.cfm` use CFML tag syntax
- Files ending with `-script.cfm` use CFScript syntax
